# Fastlane

Local release automation for this Expo dev-build app — **no EAS**. Native
`ios/` and `android/` folders are generated on demand by `expo prebuild`, so
every lane regenerates them first (via `../scripts/*.sh`).

## One-time setup

```bash
gem install bundler
bundle install
```

## Required environment variables

Nothing app-specific is committed — set these in your shell or CI secrets:

| Variable | Used by | Notes |
|---|---|---|
| `APP_BUNDLE_ID` | both | e.g. `com.yourco.yourapp` |
| `APPLE_ID` | iOS | your Apple developer account email |
| `APPLE_TEAM_ID` | iOS | 10-char team id |
| `ASC_KEY_ID` / `ASC_ISSUER_ID` / `ASC_KEY_PATH` | iOS | App Store Connect API key (`.p8` path kept outside the repo) |
| `MATCH_GIT_URL` | iOS | private git repo holding your signing certs (used by `match`) |
| `PLAY_JSON_KEY_PATH` | Android | path to the Play service-account JSON (outside the repo) |

Android release builds also need a keystore wired into `android/gradle.properties`
(regenerated by prebuild — configure it via a config plugin or `~/.gradle`).

## Lanes

```bash
bundle exec fastlane ios certs        # sync signing (run once per machine)
bundle exec fastlane ios beta         # build + upload to TestFlight
bundle exec fastlane android internal # build + upload to Play internal track
bundle exec fastlane android beta     # build + upload to Play beta track
```

Or via npm: `npm run ios:beta`, `npm run android:internal`, `npm run android:beta`.
